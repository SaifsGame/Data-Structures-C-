# 🕸️ Graph Data Structures (C++)

> **"To understand the network, you must build the map."**

### 📖 About This Project
This repository contains a **custom implementation** of Graph Data Structures written entirely in **C++**. Unlike standard library implementations, this project constructs graphs from the ground up, focusing on manual memory management, pointer arithmetic, and algorithmic efficiency.

It serves as a deep dive into how Non-Linear Data Structures function under the hood.

### ⚡ Key Features
* 🛠️ **Custom Built:** No heavy reliance on STL for the core graph logic.
* 🔄 **Representations:** Implemented using both **Adjacency Matrix** and **Adjacency Lists**.
* 🚀 **Performance:** Optimized C++ code for fast insertion and deletion of nodes.

### 🧠 Algorithms Implemented
* [x] Breadth-First Search (BFS)
* [x] Depth-First Search (DFS)
* [x] Cycle Detection
* [ ] Shortest Path (Dijkstra) *(Coming Soon)*
