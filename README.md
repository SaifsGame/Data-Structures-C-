### 📖 About This Project
This repository is dedicated to the manual implementation of fundamental **Data Structures** and **Abstract Data Types (ADTs)** using **C++**. 

Instead of relying on pre-built libraries, I am building these components from the ground up. This approach allows me to master:
* **Manual Memory Management** (Pointers & References)
* **Algorithmic Efficiency** (Time & Space Complexity)
* **Internal Architecture** of complex data containers
